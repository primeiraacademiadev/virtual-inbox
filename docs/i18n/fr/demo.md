# Découvrir Virtual Inbox

Parcours guidé sans autre application.

## Premier e-mail

Créez une boîte dans la console, sélectionnez-la et choisissez Envoyer. Le trafic de démonstration traverse le port 3001/3444 puis SMTP sur le port 2525. Les pièces jointes sont prises en charge.

## Premier SMS

Créez un numéro simulé et envoyez un SMS de test. Aucun opérateur mobile réel n'est contacté.
