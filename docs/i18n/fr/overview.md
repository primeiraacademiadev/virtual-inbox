# Virtual Inbox — Prise en main

Serveur de test éphémère pour e-mails SMTP et SMS simulés.

## Démarrage

Installez Node.js 24+, npm et OpenSSL. Exécutez `npm install`, `npm install --prefix web`, `npm run build:console`, puis `npm run dev`. Ouvrez `https://localhost:3443` après avoir approuvé l'autorité locale, ou `http://localhost:5173` avec `npm run dev:console`.

## Choisir un parcours

Explorez la démonstration, connectez une application avec le guide d'intégration, ou vérifiez les messages avec le SDK TypeScript.
