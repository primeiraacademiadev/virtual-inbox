# Virtual Inbox — Getting started

Disposable SMTP email and simulated SMS server for development and testing.

## Start

Install Node.js 24+, npm and OpenSSL. Run `npm install`, `npm install --prefix web`, `npm run build:console`, then `npm run dev`. Open `https://localhost:3443` after trusting the local CA, or use `http://localhost:5173` with `npm run dev:console`.

## Choose a journey

Try the demo guide, connect your application using the integration guide, or assert deliveries with the TypeScript SDK.
