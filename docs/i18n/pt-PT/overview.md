# Virtual Inbox — Guia inicial

Servidor de teste efémero para email SMTP e SMS simulado.

## Começar

Instala Node.js 24+, npm e OpenSSL. Executa `npm install`, `npm install --prefix web`, `npm run build:console` e `npm run dev`. Abre `https://localhost:3443` depois de confiar na CA local ou `http://localhost:5173` com `npm run dev:console`.

## Escolher um percurso

Para experimentar, começa pelo guia de demonstração. Para integrar uma aplicação, consulta o guia de integração. Para testes automatizados, consulta o SDK.
